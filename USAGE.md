# Инструкция по использованию "Карты желаний"

## 🎯 Основные возможности

### 1. Начало работы
- Откройте приложение по адресу http://localhost:5173
- Нажмите кнопку **"Демо-вход"** для быстрого доступа к функционалу
- Или воспользуйтесь кнопками "Войти"/"Зарегистрироваться" для создания аккаунта

### 2. Главная страница
После авторизации вы увидите:
- **Заголовок** "Мои желания"
- **Поисковую строку** для фильтрации желаний
- **Выпадающий список категорий** для фильтрации
- **Кнопку "Добавить желание"** для создания новых записей
- **Сетку карточек** с вашими желаниями

### 3. Создание желания
1. Нажмите кнопку **"Добавить желание"**
2. Заполните форму:
   - **Название** (обязательно)
   - **Описание** (необязательно, но рекомендуется)
   - **Категория** - выберите из списка
   - **Приоритет** - от 1 до 5 звезд
   - **Дедлайн** - установите дату, если нужно
3. Нажмите **"Создать желание"**

### 4. Просмотр деталей желания
- Кликните на любую **карточку желания** для открытия модального окна
- В модальном окне вы увидите:
  - Полное описание
  - Категорию с цветовой меткой
  - Статус выполнения
  - Приоритет
  - Дату создания и дедлайн
  - Прогресс выполнения

### 5. Фильтрация и поиск
- Используйте **поле поиска** для поиска по тексту желаний
- Используйте **выпадающий список категорий** для фильтрации
- Для сброса фильтров выберите "Все категории" и очистите поле поиска

### 6. Навигация
- **Логотип** в левом верхнем углу
- **Имя пользователя** и **аватар** справа
- Кнопка **"Выйти"** для завершения сеанса

## 📱 Адаптивный дизайн

Приложение полностью адаптировано под разные устройства:

### Десктоп (ширина > 768px)
- Три колонки карточек желаний
- Боковая навигация
- Полноразмерные формы

### Планшет (ширина 480px-768px)
- Две колонки карточек
- Упрощенная навигация
- Адаптированные формы

### Мобильные устройства (ширина < 480px)
- Одна колонка карточек
- Вертикальное меню
- Компактные формы
- Увеличенные кнопки для удобства нажатия

## 🔧 Расширенные функции

### Категории желаний
Приложение включает 8 предустановленных категорий:
1. **Путешествия** (красный)
2. **Здоровье** (бирюзовый)
3. **Материальное** (голубой)
4. **Личностный рост** (зеленый)
5. **Карьера** (желтый)
6. **Отношения** (фиолетовый)
7. **Хобби** (зелено-голубой)
8. **Другое** (оранжевый)

### Статусы выполнения
Каждое желание может иметь один из 4 статусов:
1. **Активно** (зеленый) - цель поставлена
2. **В процессе** (оранжевый) - работа над целью ведется
3. **Выполнено** (синий) - цель достигнута
4. **Отменено** (красный) - цель отменена

### Система приоритетов
Приоритет отображается звездами:
- ⭐ - Низкий приоритет
- ⭐⭐ - Средний приоритет
- ⭐⭐⭐ - Высокий приоритет
- ⭐⭐⭐⭐ - Очень высокий приоритет
- ⭐⭐⭐⭐⭐ - Критический приоритет

## 💡 Советы по эффективному использованию

### Для личного использования
1. **Регулярно обновляйте статусы** желаний
2. **Устанавливайте реалистичные дедлайны**
3. **Используйте описания** для конкретизации целей
4. **Сортируйте по приоритету** для фокусировки на главном

### Для командной работы
1. **Единая система категорий** для всей команды
2. **Регулярные ревью** прогресса
3. **Четкие формулировки** желаний
4. **Отслеживание зависимостей** между желаниями

## 🛠️ Решение проблем

### Проблемы с запуском
1. **Приложение не запускается:** проверьте установлены ли все зависимости (`npm install`)
2. **Порт занят:** остановите другие приложения на порту 5173 или измените порт в `vite.config.js`
3. **Ошибки в консоли:** проверьте логи разработчика в браузере

### Проблемы с интерфейсом
1. **Карточки не отображаются:** проверьте подключение к Redux store
2. **Формы не работают:** проверьте консоль на наличие JavaScript ошибок
3. **Стили не применяются:** проверьте импорты CSS файлов
